# Test Interactivo de Oposiciones

Este repositorio contiene los archivos necesarios para alojar tu test interactivo en GitHub Pages de forma gratuita y que puedas acceder a él desde cualquier dispositivo (móvil, tablet o PC).

## 🚀 Cómo publicar tu web en GitHub (Paso a Paso)

1. **Crea una cuenta en GitHub**: Si no tienes una, regístrate en [github.com](https://github.com/).
2. **Crea un nuevo repositorio**:
   - Arriba a la derecha, haz clic en el botón **`+`** y luego en **New repository**.
   - Ponle un nombre, por ejemplo: `test-oposiciones`.
   - Asegúrate de que esté en **Public**.
   - Haz clic en **Create repository**.
3. **Sube los archivos**:
   - En la pantalla que aparece, haz clic en el enlace **"uploading an existing file"**.
   - Arrastra todos los archivos de esta carpeta (`index.html`, `app.js`, `README.md`) y haz clic en **Commit changes**.
   - *(Opcional: Si descargaste el archivo HTML completo de nuestra conversación anterior, renómbralo a `index.html` y súbelo reemplazando el de este ZIP para tener las 100 preguntas).*
4. **Activa GitHub Pages (La magia)**:
   - Ve a la pestaña **Settings** (Configuración) de tu repositorio.
   - En el menú lateral izquierdo, haz clic en **Pages**.
   - En la sección *Build and deployment*, donde dice *Source*, asegúrate de que ponga *Deploy from a branch*.
   - Justo debajo, en *Branch*, selecciona **`main`** (o `master`) y haz clic en **Save**.
5. **¡Listo!**
   - En unos un par de minutos, si recargas la página de **Pages**, verás un mensaje que dice: *"Your site is live at https://tu-usuario.github.io/test-oposiciones"*.
   - ¡Ese es el enlace que puedes guardar en favoritos o compartir!

## ⚙️ Reglas de Corrección
- **Acierto**: +1 punto (verde)
- **Fallo**: -0.333 puntos (rojo, y marca la correcta en azul)
- **En blanco**: 0 puntos (marca la correcta en azul)
- Incluye recuentos parciales por bloques y recuento total.
