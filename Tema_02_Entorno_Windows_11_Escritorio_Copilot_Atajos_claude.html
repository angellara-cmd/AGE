📌Lo que he actualizado respecto al manual (actualización de enero de 2026):
  • 2026 Versiones: la vigente es Windows 11 26H2 (29-9-2026), con dos años de soporte en Home y Pro. La 24H2 Home/Pro dejó de recibir actualizaciones el 13-10-2026, y la 25H2 las recibe hasta el 12-10-2027. Windows 11 SE (educativa de gama baja) perdió el soporte en octubre de 2026.
  • 2026 Menú Inicio y barra de tareas:
    • El menú Inicio rediseñado (una sola página desplazable con la sección «Todas» en vista de categorías o de cuadrícula) llegó a casi todos los equipos con la actualización de enero de 2026.
    • Con 26H2 se puede elegir el tamaño del menú y mostrar u ocultar las secciones Anclado, Recientes y Todas.
    • La barra de tareas vuelve a poder moverse a cualquier borde y tiene un tamaño pequeño.
    • El botón de apagado ofrece reiniciar y apagar sin instalar actualizaciones.
  • 2026 Copilot:
    • Activación por voz «Hey Copilot» (opcional); se abre también con la tecla Copilot, Win + C o Alt + Espacio.
    • Copilot+ no es una «versión» de Copilot: es una categoría de PC con NPU de 40 TOPS o más, 16 GB de RAM y 256 GB de SSD.
    • Microsoft ha retirado Copilot de Recortes, Fotos, Bloc de notas y Widgets, y quita sus acciones del Explorador entre noviembre y diciembre de 2026.
    • Microsoft 365 Copilot ya no usa solo modelos de OpenAI: también ofrece modelos Claude de Anthropic.
  • Atajos que han cambiado:
    • Win + Mayús + C (botones de acceso) es de Windows 8; hoy Win + C abre Copilot (o la aplicación que se configure).
    • Win + Y no sirve: Windows Mixed Reality se eliminó en la 24H2.
    • Win + Ctrl + S abría el Reconocimiento de voz, en desuso: su sustituto es el Acceso por voz.
    • Win + Ctrl + V abre la salida de sonido en Configuración rápida, no «notificaciones animadas».
    • Faltan atajos clave: Win + Mayús + S (Recortes), Win + Ctrl + D (nuevo escritorio virtual) y Win + Ctrl + flechas (cambiar de escritorio).
  • Erratas y precisiones:
    • Windows 11 exige UEFI con un sistema compatible con arranque seguro (Secure Boot capable), no necesariamente activado. Tampoco recoge el procesador de 1 GHz con 2 núcleos, DirectX 12 ni la pantalla de 720p.
    • «Sacudir para minimizar» (Aero Shake) viene desactivado en Windows 11; se activa en Configuración > Sistema > Multitarea.
    • Faltan ediciones: Pro for Workstations, Pro Education, IoT Enterprise y SE.
    • Erratas de imprenta: «Ctrol + ESC» (es Ctrl + Esc), «tamaña anterior» (tamaño) y el signo «k» que aparece en lugar de la flecha «>» en las rutas de menú.

Parte 1 · El sistema operativo Windows 11

1

El sistema operativo y Windows 11

Manual 1
  • Sistema operativo: los programas que controlan el funcionamiento interno del ordenador y hacen de intermediarios entre el usuario y el equipo.
  • Windows 11:
    • lo desarrolla Microsoft y pertenece a la familia Windows NT;
    • su principal medio de interacción es una interfaz gráfica (GUI): ventanas, iconos, menús, ratón y teclado;
    • mantiene la compatibilidad con la línea de comandos.
  • Características:
    1. multiusuario: perfiles con permisos diferenciados;
    2. multitarea: varios procesos y aplicaciones a la vez;
    3. interfaz gráfica integrada, cargada por defecto al arrancar;
    4. preparado para la red, cableada e inalámbrica.
  • 2026 Versiones: hay una actualización anual («H2»). La vigente es la 26H2 (29-9-2026); Home y Pro reciben 24 meses de soporte, y Enterprise y Education, 36.
2

Requisitos de instalación

Manual 1
  • Finalidad: garantizan el funcionamiento y, sobre todo, la seguridad desde el arranque.
  • Requisitos que cita el manual:
    • procesador de 64 bits;
    • 4 GB de RAM;
    • 64 GB de almacenamiento;
    • firmware UEFI con arranque seguro (Secure Boot), que impide ejecutar software no autorizado al iniciar;
    • módulo TPM 2.0, que protege la información y las credenciales.
  • Requisitos oficiales que el manual omite:
    • procesador compatible de 1 GHz o más con 2 núcleos o más;
    • gráfica compatible con DirectX 12 (controlador WDDM 2.0);
    • pantalla de 720p y más de 9 pulgadas;
    • conexión a Internet y cuenta Microsoft para configurar la edición Home.
  • 2026 PC Copilot+: además de lo anterior, una NPU de 40 TOPS o más, 16 GB de RAM DDR5/LPDDR5 y 256 GB de SSD.
3

Fundamentos del sistema operativo

Manual 2
  • Gestión de procesos: controla la ejecución y la prioridad. Un proceso es un programa en ejecución junto con sus recursos (memoria, tiempo de CPU, identificadores…).
  • Gestión de memoria: asigna recursos a las aplicaciones. Usa memoria virtual, que apoya la memoria física con almacenamiento secundario.
  • Gestión de entrada/salida: mediante controladores (drivers), que hacen de intermediarios entre el hardware y el sistema operativo.
  • Gestión del sistema de archivos:
    • NTFS es el predeterminado;
    • la información se estructura en unidades, carpetas y archivos.
  • Gestión de usuarios, permisos y seguridad: cuentas de usuario y control de acceso (bloque 4).
4

Cuentas de usuario y UAC

Manual 2
  • Cuenta estándar (limitada):
    • puede hacer cambios que solo le afectan a ella (iconos, fondo…);
    • no puede hacer cambios que afecten al sistema, como tocar el registro o instalar programas.
  • Cuenta de administrador:
    • tiene más privilegios y puede configurar el sistema, el registro, instalar programas y gestionar a otros usuarios;
    • sus privilegios no son absolutos: el nivel máximo solo lo tiene el kernel, con el usuario SYSTEM.
  • Cuenta Microsoft: asociada a la nube; facilita la tienda de aplicaciones y la sincronización de preferencias.
  • Control de cuentas de usuario (UAC): cuando una acción requiere privilegios de administrador, muestra un cuadro de confirmación.
    • Al administrador le pide que confirme.
    • Al usuario estándar le pide las credenciales de un administrador.
  • Otros mecanismos: la protección frente a amenazas y la separación de privilegios.
5

Ediciones de Windows 11

Manual 2.1
  • Rasgos comunes: todas comparten núcleo y experiencia de usuario (escritorio, barra de tareas, menú Inicio). Se diferencian en la administración, la seguridad y el uso profesional.
  • Ediciones del manual:
    • Home: uso doméstico y personal;
    • Pro: entornos profesionales y pequeñas empresas;
    • Enterprise: grandes organizaciones y Administraciones Públicas, con gestión centralizada;
    • Education: similar a Enterprise, para centros educativos.
  • Otras ediciones (complemento):
    • Pro for Workstations;
    • Pro Education;
    • IoT Enterprise;
    • 2026 SE, para portátiles escolares, sin soporte desde octubre de 2026.
6

Inicio de Windows y acceso al escritorio

Manual 2.2
  • Tipos de inicio:
    • normal: carga todo (entorno gráfico, servicios, controladores y aplicaciones de inicio); es el uso diario;
    • a prueba de errores (modo seguro): solo los componentes esenciales, con un mínimo de controladores y servicios; sirve para diagnosticar y recuperar.
  • Secuencia de acceso:
    1. Pantalla de bloqueo: una capa de protección que muestra la hora, la fecha y las notificaciones; se pasa con una tecla o un clic.
    2. Inicio de sesión: el usuario se autentica con contraseña o con Windows Hello (PIN, reconocimiento facial o huella). Los datos biométricos se guardan protegidos en el equipo y no se transmiten por la red.
    3. Escritorio: se carga el perfil del usuario y se muestra el entorno de trabajo.

Parte 2 · El entorno gráfico

7

Ventanas y su gestión

Manual 3.1
  • Elementos de la GUI: ventanas (contenedores), iconos (representaciones), menús (opciones) y cuadros de diálogo (confirmación y configuración).
  • Ventana: el elemento básico de interacción. Puede:
    • moverse arrastrándola desde la barra de título;
    • redimensionarse desde los bordes o las esquinas;
    • minimizarse: se oculta en la barra de tareas sin cerrarse;
    • maximizarse o restaurarse;
    • cerrarse.
  • Partes: barra de título, botones de control, área de contenido y, a veces, barras de herramientas y de estado.
  • Ventana activa: la que recibe la entrada del teclado.
  • Gestión avanzada:
    • sacudir para minimizar (Aero Shake): minimiza todas menos la activa; en Windows 11 viene desactivado;
    • Win + D: muestra el escritorio;
    • Alt + Tab: alterna entre ventanas;
    • Win + flechas: acopla las ventanas;
    • Alt + F4: cierra la ventana activa.
  • Snap Layouts (Diseños de ajuste): organizan varias ventanas en disposiciones predefinidas. Se abren pasando el cursor sobre Maximizar/Restaurar o con Win + Z.
8

Iconos y accesos directos

Manual 3.2
  • Icono: una representación gráfica de un programa, archivo, carpeta o función. Están en el escritorio o en la barra de tareas.
  • Acceso directo:
    • se reconoce por la flecha en la esquina inferior izquierda;
    • abre un elemento que está en otra ubicación;
    • los archivos se abren con el programa asociado a su extensión.
  • Interacción:
    • doble clic (o un clic, según la configuración): abre el elemento;
    • clic derecho: abre el menú contextual.
9

Menús contextuales y cuadros de diálogo

Manual 3.3 y 3.4
  • Menú contextual:
    • aparece con el botón derecho y ofrece opciones del elemento;
    • en Windows 11 tiene un diseño simplificado; el menú clásico sigue en «Mostrar más opciones»;
    • con teclado se abre con Mayús + F10 o con la tecla de menú contextual (a la derecha de la barra espaciadora).
  • Cuadros de diálogo: tienen un diseño modernizado, con bordes redondeados. Evitan acciones críticas accidentales (eliminar, sobrescribir, cambiar la configuración) y se integran con el UAC.
    • Modal: bloquea la ventana principal hasta que respondes. Ejemplo: cerrar sin guardar en Word (Guardar / No guardar / Cancelar).
    • No modal: permite seguir trabajando. Ejemplo: Buscar y reemplazar en Word.
10

Uso del ratón y del teclado

Manual 3.5
  • Ratón:
    • clic izquierdo: seleccionar o ejecutar;
    • doble clic: abrir;
    • clic derecho: menú contextual;
    • clic central o rueda: abrir o cerrar pestañas en el navegador;
    • arrastrar y soltar: mover, copiar o crear accesos directos;
    • rueda: desplazarse; con Ctrl, zoom.
  • Teclas especiales:
    • Intro: confirmar;
    • Esc: cancelar o cerrar;
    • Tab: pasar de un campo a otro;
    • Mayús, Ctrl y Alt: se combinan con otras teclas;
    • tecla Windows: abre el menú Inicio o activa atajos del sistema.
  • 2026 Tecla Copilot: los teclados nuevos la incluyen. Desde octubre de 2026 se puede reasignar sin programas de terceros.

Parte 3 · El escritorio

11

El escritorio y su organización

Manual 4
  • Escritorio: el área principal de trabajo tras iniciar sesión. Sus elementos son el fondo, los iconos y accesos directos y la barra de tareas.
  • Menú contextual del fondo:
    • Ver: tamaño de los iconos (grandes, medianos o pequeños), Alinear a la cuadrícula, Organizar automáticamente y Mostrar u ocultar iconos del escritorio;
    • Ordenar por: nombre, tamaño, tipo o fecha;
    • Actualizar y otras opciones clásicas, en «Mostrar más opciones».
  • Personalización: en Configuración > Personalización se eligen el fondo, los colores, los temas y las fuentes.
12

La barra de tareas y sus elementos

Manual 4.1 y 4.2
  • Posición: por defecto, abajo, con los iconos centrados (la alineación se puede cambiar). 2026 Con 26H2 vuelve a poder moverse a cualquier borde y tiene un tamaño pequeño.
  • Elementos:
    • Widgets (Win + W): contenido dinámico y personalizado;
    • Inicio (tecla Windows o Ctrl + Esc);
    • Búsqueda (Win + S o Win + Q): archivos, aplicaciones, configuración y web;
    • Vista de tareas (Win + Tab): todas las ventanas y los escritorios virtuales; es más completa que Alt + Tab;
    • Aplicaciones (Win + T): anclar, desanclar y reordenar;
    • Jump List: el menú del clic derecho (o pulsación larga) sobre una aplicación en la barra o en Inicio, con contenidos recientes y acciones.
  • Bandeja del sistema:
    • las aplicaciones en segundo plano;
    • la Configuración rápida (Win + A): red, volumen y batería;
    • el calendario y centro de notificaciones (Win + N).
  • Centro de actividades: el de Windows 10 se ha dividido en el centro de notificaciones y la Configuración rápida.
13

El menú Inicio

Manual 4.2.2
  • Función: es el punto central de acceso. Desde él se inician aplicaciones, se abren documentos recientes, se busca, se configura y se cierra sesión, reinicia o apaga. Ya no tiene baldosas dinámicas.
  • Zonas:
    1. Búsqueda, arriba;
    2. Aplicaciones ancladas (anclar, desanclar y reordenar);
    3. Recomendaciones y Todas las aplicaciones;
    4. Cuenta (bloquear, cambiar de usuario, cerrar sesión), accesos a carpetas y Configuración, y botón de Inicio/Apagado: Suspender, Apagar y Reiniciar.
  • Personalización: aparece centrado y se personaliza en Configuración > Personalización.
  • Menú Win + X («de usuario avanzado» o de vínculo rápido):
    • se abre con clic derecho sobre Inicio o con Win + X;
    • da acceso a herramientas de administración, no a aplicaciones.
  • 2026 Nuevo diseño:
    • una sola página desplazable;
    • la sección «Todas» se ve por categorías (una categoría necesita al menos tres aplicaciones) o en cuadrícula;
    • con 26H2 se elige el tamaño y se muestran u ocultan Anclado, Recientes y Todas.

Parte 4 · Copilot

14

Copilot: concepto, acceso y funciones

Manual 5.1-5.3.2
  • Concepto:
    • es el asistente de Microsoft basado en IA;
    • funciona con lenguaje natural y reduce la carga cognitiva;
    • está integrado en Word, Excel, Outlook, PowerPoint, Teams, Windows 11 y Power BI.
  • Modelos: el manual cita los de Microsoft y OpenAI. 2026 Microsoft 365 Copilot ofrece también los modelos Claude de Anthropic.
  • Objetivo: asistir, no sustituir. Funciona como un «copiloto».
  • Acceso:
    • con el icono de la barra de tareas o buscando «Copilot» en Inicio; en las versiones recientes aparece en una ventana flotante centrada;
    • 2026 también con la tecla Copilot, Win + C, Alt + Espacio y «Hey Copilot».
  • Funciones:
    • asistencia en la configuración: según el manual, guía paso a paso sin aplicar los cambios; en los PC Copilot+ ya existe el agente de Configuración;
    • búsqueda combinada, local y en línea;
    • tareas administrativas: redactar y organizar;
    • integración con Edge: analiza la página abierta;
    • Copilot Vision: interpreta lo que hay en pantalla.
15

Funciones avanzadas, PC Copilot+ y privacidad

Manual 5.3.3 y 5.3.4
  • Requisito: algunas funciones exigen una NPU (unidad de procesamiento neuronal). Copilot+ es la categoría de PC que la incorpora con 40 TOPS o más.
  • Funciones:
    • Recall: recupera lo que se vio antes mediante una línea de tiempo; es exclusivo de los Copilot+, en versión preliminar, opcional y protegido con Windows Hello;
    • Click to Do: propone acciones según el contexto (Win + clic);
    • memoria personalizada: recuerda preferencias;
    • Copilot Actions: hace tareas en Edge, como reservas o formularios;
    • Copilot Pages y Shopping: organizan ideas y comparan precios.
  • Restricciones: pueden limitarse en redes corporativas, centros educativos y Administraciones Públicas.
  • Privacidad:
    • se ajusta en Configuración > Privacidad y seguridad;
    • la cuenta Microsoft permite revisar y borrar el historial;
    • los administradores controlan Copilot en la organización.
  • 2026 Repliegue de Copilot: Microsoft lo ha quitado de Recortes, Fotos, Bloc de notas y Widgets, y retira 8 acciones del Explorador entre noviembre y diciembre de 2026.

Parte 5 · Atajos de teclado

Los atajos imprescindibles

Manual 6.1-6.6
  • Accesibilidad:
    • Win + +: Lupa; Win + Esc la cierra;
    • Ctrl + Alt + I: invertir colores;
    • Win + Ctrl + Intro: Narrador;
    • Win + Ctrl + O: teclado en pantalla;
    • Win + U: Accesibilidad;
    • Mayús derecha 8 segundos: teclas de filtro;
    • Mayús 5 veces: teclas especiales;
    • Bloq Num 5 segundos: teclas de alternancia;
    • Alt izquierda + Mayús izquierda + Impr Pant: contraste alto.
  • Generales:
    • Ctrl + X, C, V, Z e Y;
    • F2 (cambiar nombre), F3 (buscar), F5 o Ctrl + R (actualizar), F10 (barra de menús);
    • Ctrl + Mayús + Esc: Administrador de tareas;
    • Mayús + Supr: eliminar sin pasar por la Papelera;
    • Ctrl + D o Supr: a la Papelera;
    • Alt + Intro: propiedades.
  • Cuadros de diálogo:
    • Ctrl + Tab y Ctrl + Mayús + Tab: pestañas;
    • Tab y Mayús + Tab: opciones;
    • barra espaciadora: casillas;
    • Retroceso: carpeta superior en Abrir y Guardar como;
    • F4: desplegar la lista.
  • Tecla Windows:
    • A (Configuración rápida), D (escritorio), E (Explorador), I (Configuración), L (bloquear), M (minimizar), N (notificaciones);
    • R (Ejecutar), S (búsqueda), V (historial del portapapeles), X (vínculo rápido), Z (diseños de ajuste);
    • punto (emojis) y Tab (Vista de tareas).
  • Explorador:
    • Ctrl + Mayús + N: nueva carpeta;
    • Alt + P: panel de vista previa;
    • Alt + flecha arriba: carpeta contenedora;
    • Alt + D: barra de direcciones;
    • Ctrl + N y Ctrl + W: abrir y cerrar ventana.
  • Barra de tareas:
    • Mayús + clic: nueva instancia;
    • Ctrl + Mayús + clic: como administrador.
  • 2026 Nuevos:
    • Win + Mayús + S: Recortes;
    • Win + Ctrl + D: nuevo escritorio virtual;
    • Win + Ctrl + flechas: cambiar de escritorio;
    • Win + C: Copilot.
